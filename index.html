ID・パスワード保存テスト

このページは特定のブラウザでの ID・パスワード保存機能の動作確認用です。フォームを送信したときに保存ダイアログが正しく表示されるか、再訪時に自動入力 ActionSheet が出るかを確認します。

テストの進め方

  1. 下記からテストパターンを選びます
  2. ID とパスワードを入力して送信ボタンを押します
  3. 「このパスワードを保存しますか？」のダイアログが出たら「保存」を押します
  4. 戻って同じページを開き、自動入力 ActionSheet が出るかを確認します

テストパターン

通常フォーム送信テスト →

HTML の <form> を使った 3 種類の送信パターン。一般的な Web サイトで多く使われる形式です。

SPA 形式送信テスト →

React や Vue 等の SPA フレームワークがよく使う 4 種類の送信パターン。fetch や pushState による画面遷移も含みます。

Google 式 2 段階ログインテスト →

ID を先に入力させ、次画面でパスワードを入力させる 2 段階パターン。Google (accounts.google.com) や Microsoft (login.microsoftonline.com) が採用する形式です。

モーダル / ダイアログ型ログインテスト →

ページ遷移を伴わず、モーダルウィンドウ内でログインフォームが出現するパターン。EC サイトのカート内ログイン等でよく見る形式です。

期待される動作

  • 初回送信時：「このパスワードを保存しますか？」のダイアログが表示される
  • 「保存」を押すと iOS のキーチェーンに保存される
  • 再訪時：「保存されたパスワードを自動入力しますか？」の ActionSheet が表示される
  • 「自動入力」を押すと ID/パスワード欄に値が自動で入る
