ようこそ さん

パスワードだけの単独ページ。前画面で入力された username は hidden で運びます。
テスト対象ブラウザが host 単位で credential を保持していれば、PW 欄のみの自動入力が期待されるページです。

実装詳細（開発者向け） 
このページの構造:
  - visible input: password のみ
  - hidden input: username (autocomplete="username")
  - form action="success.html" method="GET"

想定される検知結果:
  - readLoginForm.js の現在の実装では、visible な username 欄が無いため
    フォーム認識に失敗する可能性がある (hidden を username として拾うかは実装次第)
  - Xamarin 版は input[type=password] のみを基準に走査するため、
    PW 欄検出→ credential 引き当て→自動入力 の流れが動く
  - PR #247 の readLoginForm.js は visible な username 欄も要求するため、
    hidden username のみでは検出漏れの可能性
