通常フォーム送信テスト

ID とパスワードを入力して、3 種類のいずれかの送信ボタンを押してください。

HTML 標準の送信方法（送信ボタンを押すと submit イベントが発火します）。一般的なログインフォームと同じ動作です。

JavaScript からフォームを送信する方式。送信時に submit イベントが発火するため、フォームのバリデーション処理が走ります。React や Vue で標準的に使われます。

JavaScript からフォームを送信する方式。submit イベントが発火しないため、バリデーション処理がスキップされる古い書き方です。テスト対象ブラウザの保存機能では取りこぼされる可能性があります。

実装詳細（開発者向け） 
パターン A: button[type=submit] のネイティブ送信
  - submit イベント発火する
  - WKNavigationType.formSubmitted も発火する

パターン B: form.requestSubmit() — submit イベントを発火する JS 送信
  - submit イベント発火する
  - WKNavigationType.formSubmitted も発火する

パターン C: form.submit() — submit イベントを bypass する JS 送信
  - submit イベント発火しない
  - WKNavigationType.formSubmitted は発火する（実機確認済）
  - JS submit listener 方式では取りこぼされる可能性

WKNavigationType.formSubmitted が発火するかを確認するためのテストパターン。
遷移先 success.html にはフォームがないため、3 重防御の DOM 再判定で「成功推定」となります。
