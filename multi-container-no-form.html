パターン R: form 要素なし × 複数コンテナ

<form> 要素を使わず、<section class="group"> で 2 つのログインコンテナを配置。各コンテナは ID 欄 + PW 欄 + type=button の送信ボタンを持つ。

resolveSearchRoot の container hop (dialog/section/article/main/div, 5 hop) が押したボタンの祖先 section を root にする挙動を検証。設計上は複数コンテナも「複数のログインフォーム」相当で対象外。

resolveSearchRoot(eventTarget):
  eventTarget.closest('form') が null (form 要素なし)
  → container hop で [role="dialog"],section,article,main,div を 5 hop まで
  → PW 欄を含む祖先 (section) を root に採用

修正 (scanLoginForm):
  if (root !== document && findVisiblePasswordInput(document) === null) {
    return null;
  }
  → root=section で通過しても document 全体で複数 PW 検知 → null
